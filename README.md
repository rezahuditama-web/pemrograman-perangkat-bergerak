## 4. Jawaban Pertanyaan Refleksi
1. Pilihan Native vs Flutter

Saya memilih Native jika aplikasi membutuhkan performa tinggi dan banyak menggunakan fitur sistem operasi. Flutter lebih cocok untuk pengembangan aplikasi lintas platform dengan satu basis kode.

2. Prinsip UI = f(state)

Prinsip UI = f(state) berarti tampilan akan otomatis berubah mengikuti perubahan data atau state, sehingga pengembang dapat lebih fokus mengelola data aplikasi.

3. Pentingnya Conventional Commits

Conventional Commits membuat riwayat perubahan kode lebih rapi dan mudah dilacak. Riwayat tersebut juga dapat menjadi dokumentasi perkembangan proyek di GitHub.
